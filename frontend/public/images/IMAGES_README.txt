## How to replace
1. Drop your JPG/PNG in the matching folder
2. Open frontend/src/assets/images.ts
3. Change .svg to .jpg (or .png) for that file
4. Save — done!

## Tips
- Recommended size: 600x400 for feature photos, 1200x600 for hero
- Use .jpg for photos, .png for images with transparency
- Keep file sizes under 300KB for fast loading (use tinypng.com)
